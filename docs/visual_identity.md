# Visual Brand Identity & Mascot System

MergeStudio uses a disciplined visual identity built on Swiss minimalism, precision geometry, and computer-science metaphors.

---

## 1. Mascot & Symbolic Metaphor: The Surgical Chimera Owl

```
              /\       /\
             /  \_____/  \
            /  / \   / \  \
           |  | (o) (o) |  |
            \  \   ^   /  /
             \__\_---_/__/
                | === |
                /     \
```

- **Core Metaphor**: The owl is nature's most focused predator, possessing 360-degree rotational perception and binocular depth precision. In MergeStudio, the **Surgical Chimera Owl** represents the neuro-surgeon of large language models: inspecting high-dimensional parameter spaces, slicing transformer layers with pinpoint accuracy, and splicing synaptic weights across models.
- **Hyperspherical SLERP Core**: The chest plate features a glowing electric cyan geodesic ring arc, representing spherical interpolation angles ($\Omega$) on $N$-dimensional hyperspheres.
- **Surgical Layer Slices**: The faceted origami feathers and breastplate tiers mirror transformer block slices (`model.layers.X`) in passthrough frankenmerging.
- **Amber Precision Beak**: A sharp gold chevron beak symbolizing deterministic arithmetic sign election in TIES-Merging.

---

## 2. Mathematical Vector Construction

The official mark is constructed on a 1024x1024 coordinate system:
- **Luxury White Squircle Container**: `viewBox="0 0 1024 1024"`, `rx="220"`, fill `#ffffff`, stroke `#e2e8f0` (6px).
- **Hexagonal Architectural Gateway**: Deep charcoal `#0f172a` outer frame (36px width) with an inner dashed cyan telemetry rail (`#00f5ff`, opacity 0.45).
- **Solid Obsidian Silhouette**: Watertight contiguous path preventing vertex bleeding.
- **Symmetrical Origami Facets**: Volumetric facets shaded in `#0b0f19`, `#0f172a`, `#1e293b`, `#334155`, and `#475569`.
